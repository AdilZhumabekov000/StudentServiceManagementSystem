# StudentServiceManagementSystem
C-based student service management system using queues, linked lists, and stacks.

The program manages student service requests, tracks completed services, and supports undo functionality.

Features:

Register new student service requests

Manage waiting students using a FIFO queue

Serve the next student in the queue

Store completed services in a linked list

Search completed records by Student ID

Undo the most recently completed service using a stack

Display waiting and completed records

View system statistics

Data Structures

Queue — stores students waiting for service

Linked List — stores completed service records

Stack — supports undo functionality


Service Types:

The system supports several student services:

Course Registration Help

Exam Slip Printing

Fee Payment Inquiry

IT Account Support

General Academic Inquiry

Requests can also be marked as Normal or Urgent priority.

Technologies:
C
Dynamic Memory Allocation
Queue
Stack
Linked List
Structs and Pointers
Run

Purpose:

This project demonstrates how multiple data structures can work together in a practical student service management system.

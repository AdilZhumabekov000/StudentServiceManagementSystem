# StudentServiceManagementSystem
C-based student service management system using queues, linked lists, and stacks.

Smart Student Service Centre is a C-based application designed to manage student service requests. The system allows students to register requests for services such as course registration help, exam slip printing, fee payment inquiries, IT support, and general academic inquiries. Each request can also be assigned a Normal or Urgent priority.

The program uses several fundamental data structures. A FIFO queue stores students who are waiting for service, a linked list stores completed service records, and a stack is used to support the undo function. The system also allows users to search completed records by Student ID, display waiting and completed requests, and view a summary of current system activity.

This project demonstrates how queues, linked lists, stacks, pointers, structs, and dynamic memory allocation can be combined in a practical C application. It was developed to show how multiple data structures can work together to manage service requests, completed records, and undo operations within one system.
